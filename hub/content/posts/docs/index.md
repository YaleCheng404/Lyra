# 版本说明

本整合包基于上游汉化仓库 release 自动构建，并按配置组合不同 Mod 与美化资源。

文件名通常采用 `DoL-{原版版本号}-Lyra-{汉化版本号}[-polyfill][-组合后缀]-{日期}.{zip,apk}`。其中 `polyfill` 表示兼容版，适合部分旧设备或旧浏览器环境。

所有版本包含内置汉化、作弊、CSD、秋枫白桦框架、枯木逢春及音频、默示录：归途之书和极致动态 Dynamicest。保留 BESC、Hikari、UCB 和 AU-F，共八种组合，分别提供 ZIP 与 APK。

如果游戏问题能在上游汉化原版复现，请优先向上游汉化仓库反馈；如果只在本整合包复现，请向当前仓库反馈。
